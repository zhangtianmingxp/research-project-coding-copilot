# 项目文档索引

本目录用于保存项目说明、方法文档、阶段 checkpoint、当前研究总结、图表索引和 claim-to-evidence 记录。

## 推荐阅读顺序

1. 当前研究主线摘要；
2. 最近 workflow checkpoint；
3. 当前 evidence / figure index；
4. 与当前任务直接相关的方法文档；
5. 必要时再读取历史 prompt/result。

## 建议长期维护的文档

- `current_research_summary.md`
- `workflow_checkpoint_pA_pB.md`
- `decision_log.md`
- `claim_evidence_map.md`
- `figure_table_inventory.md`
- `runtime_environment.md`

## 维护规则

- 说明类 Markdown 默认使用中文；
- 每约 10-20 个重要轮次更新一次 checkpoint；
- 主线变化后同步更新推荐阅读顺序；
- 稳定结论、负结果、解释边界和关键证据不得只保留在聊天历史中；
- 不在文档中记录 API key、token、credential 或其他敏感信息。
